# M4 科学契约（2025.1 候选冻结）

日期：2026-11-04。状态：**结构契约候选；数值容差已做首轮冻结**（基于独立 I/Q8 + I/Q16 的32-seed数值研究，RTL/IP误差仍待复验）。机器参数见[config/m4-science.json](../config/m4-science.json)，研究结果见[reports/m4-00-tolerance.json](../reports/m4-00-tolerance.json)。本文件不是M4验收通过，也不替代独立浮点/定点参考。

## 1. 范围

M4只回答科学核在KU5P上的可实现能力和边界。RFSoC只作为输入格式/速率/到包节奏前提，不开发其PFB、FFT或发包器。DDR、板级输出、JTAG/光纤/PCIe/驱动不在M4范围。

## 2. 阵列与编号

- 1024物理天线、双极化，共2048路输入。
- `global_input=8*source+local`；`antenna=floor(global_input/2)`；`pol=global_input%2`。
- 位置映射必须由显式配置给出，不假设网络编号等于FFT网格顺序。
- 首轮布局：32×32规则阵列；另保留规则tile但中心不规则、同口径抖动阵列两类。
- 0.5/1.0/1.5GHz代表频率；缺真实坐标/方向图时使用明确标注的合成布局和模型。

## 3. 时间与频率

- `Fs=320MS/s`，时间FFT长度`Nfft=4096`，推进`H=4096`。
- 每bin `78.125kHz`，每`12.8µs`一个电场谱。
- L为分给一片的频率bin数；单片频带`L*Fs/Nfft`与计算速率`L*Fs/H`在H=Nfft时数值相同，后续若改变重叠必须分开计算。
- 64bit科学时间标签只作为整数/字符串传递，不转成JavaScript Number。

## 4. 波束

对每个束`b`、极化`p`、频率`f`、时刻`t`：

`E[b,p,f,t]=Σ_a mask[a,p,f,t]×w[b,a,p,f]×e[a,p,f,t]`

- 每极化1024项复权加和；复电压保留相位。
- 标量校准并入权重，必须记录权重归一化。
- 功率和极化产品在加和后生成，不能先跨时间平均电场再平方。
- 缺源贡献为零，并输出有效源数/有效权重/异常标志。
- 宽累加后统一舍入/饱和；不能中途饱和使乱序改变科学结果。

## 5. 规则二维FFTT

- 32×32对应1024规则天线；64×64是补零后的更密角度采样，不增加物理天线数或物理角分辨率。
- 完整路径：校准/映射/补零 → 行FFT → 转置 → 列FFT → 索引/极化配对 → 像素乘积 → 积分。
- 两极化分别变换；X/Y配对后产生XX、YY、XY*、YX*。
- 32²与64²必须分别报告，不能把64²补零结果当作1024天线分辨率提升。

## 6. EPIC

- 先按天线位置/波长，把电场以3×3（首候选）或5×5（误差对照）核加到规则孔径平面，再做空间FFT和瞬时极化乘积/积分。
- 最近邻只作控制，不是科学精度保证。
- 64×64只是主候选网格；必须先检查0.5–1.5GHz各代表频率下的坐标、网格间距、孔径范围和卷积支持是否容纳。
- 必须覆盖同拍同格、连续拍同格、同bank不同地址、冲突队列满、读改写旁路、帧边界清零/generation、频率相关映射、越界核支持和输出阻塞。
- 独立参考同时给“含自相关”和“去自相关”定义；真实方向图缺失时科学结论标为合成模型条件。

## 7. 精度与累加

- 输入I/Q8；波束权重I/Q16为主；系数12/16/18bit、FFT内部16/18/24bit作为筛选。
- 复乘实/虚部至少25bit；1024项和保守至少35bit。首轮候选累加36/40bit，最终按校准/权重范围重新证明。
- 3乘法实现必须计入预加位宽，不能按4乘法输入宽度直接截断。
- 定点RTL与定点oracle要求逐样本、逐标志精确一致。
- 浮点科学指标在M4-00冻结：主瓣定位、通量偏差、旁瓣/噪声、极化误差、溢出与量化损失；必须写明场景、阈值、统计长度和归一化。

## 8. 输出与反压

- 输出采用有限ready/valid FIFO；明确服务率、停顿、队列峰值和超载策略。
- 零反压只是上界对照，不是默认工作点。
- 输出携带sequence/generation/epoch/config/frequency/time、有效源/权重数、scale、fault。
- 积分窗按整数谱数K=8/80/800/4000候选；不同K不减少每个电场时刻的波束/FFT/gridding工作量。
- 缺源/缺块不延长计划时间窗，不补造样本。
- 不默认第二个100G硬核或第二QSFP可用；外部传输和主机接收未实现时保持条件性输出能力。
