# 综合与验证计划

日期：2026-11-03。本文是下一阶段计划；以下任务均未在本项目执行。

## 验收产物

每个有效结果必须能回答：精度约束是什么、一个节点真实可处理多少 MHz、多少波束或什么网格、接收/缓存/输出如何限制它、是否满足时序，以及全系统至少需几片。

最终生成 Pareto 表：`device / part / mode / N / P / C / bits / beams / grid / kernel / ingress / buffer / output / sustained_MHz / resources / routed_clock / science_error / evidence`。输出实测可持续吞吐，不用 DSP 峰值替代。

## 场景与固定契约

| 维度 | 首轮范围 |
|---|---|
| 物理阵列 | 32×32 规则；规则 tile+不规则中心；同口径随机/抖动分布 |
| 天线数量 | 逻辑 N=1024 为最终目标；64/256 用于故障定位与缩放检查 |
| 极化 | 2，先对角校准，再评估完整 Jones |
| 频率 | 0.5–0.7 和 1.3–1.5 GHz 子带；500 MHz 扩展；1 GHz 对照 |
| 总带宽 | 200/500 MHz；先从单片若干频率信道开始 |
| 时间频道化 | 4096/8192/16384；必要时二级细分 |
| 输入精度 | I/Q8 为基准，I/Q4 和 I/Q12 作量化敏感性对照 |
| 系数精度 | 每分量 12/16/18 bit |
| 内部精度 | FFT/累加 16/18/24 bit，明确每级舍入、缩放与饱和 |
| 直接波束 | 1/4/16/64/256，逼近瓶颈后在邻域细扫 |
| 空间 FFT | 32² 控制；64² 主基准；128² 压力，必要时更大 |
| EPIC 支持 | 最近邻控制；2×2/3×3/5×5，精度不够再扩展 |
| 输出 | 复电压、I、完整极化乘积/全 Stokes；约 0.1/1/10/100 ms |
| 发包块 | 1/2/4/8 个电场时刻；先按布局推导包长与科学载荷效率 |
| 接收窗口 | 10/100/1000 µs，另测 10 ms 扩展 |
| 目标时钟 | 125/200/250 MHz；关键点可增加中间档位 |

不做全维度笛卡尔积。先固定精度/布局/输出，测单位成本，再按二分和邻域扫描找能力边界；只有新瓶颈或误差出现时才扩展维度。

固定时间、频率和数值契约：

- 明确 ADC 计数到 PFB 电场时刻的映射、PFB 群延迟、频率方向、FFT bin 顺序、DDC/NCO 约定。
- 所有源共用可追溯 epoch、时钟、SYSREF/PPS/MTS 基准；板间时钟漂移和相位稳定性需单独实验。
- 输入复数为有符号 I/Q，规定字节序、时间/频率/输入布局及包长边界。新协议不能沿用旧计数器而省略科学时间标签。
- 波束为复权加和；Stokes V 正负号与馈源基一致；与独立参考约定一致。
- 固定计划积分窗，缺失数据不延长时间窗。保留有效贡献/权重和丢失原因。
- 在 200 MHz/4096 基准下优先用 1.024 ms=50 个时刻，避免把 1 ms 写成整数时刻而悄悄改变时间。

## 阶段 A：科学参考与负荷模型

建立独立浮点参考：直接相位求和、显式小规模 FX→成像、规则空间 FFT 和非规则 gridding。模拟天空含单/多点源、噪声、离轴强源、宽带瞬变、校准偏差及可控 RFI。FPGA 固定点参考不得调用 RTL 同一段逻辑来充当独立真值。

比较主瓣位置、宽度、旁瓣、通量、噪声方差、极化串扰、饱和概率、量化损失、丢包后曝光归一化和瞬变恢复。动态范围/允许通量偏差等阈值在首轮参考实验后冻结；不能只因为图像看起来正确就接受。

直接 sum 与空间 FFT 在规则点源情景应一致；EPIC 与同一核/权重的可见度成像比较，明确自相关去除、核校正和有限视场误差。最近邻核无论多省资源，都必须经过同样的精度要求。

本阶段同时冻结发包布局，计算每端口 pps、最长发包覆盖时间、每源轮询延迟、incast 和源端 pacing；接口不等实际 RFSoC 固件时明确标记 synthetic。

## 阶段 B：单位成本 OOC 综合

先做少量可复用核，而不是从完整 1024 输入顶层盲目综合：

1. 复乘/复 MAC：4 乘法与 3 乘法两种实现，扫描数据/系数位宽；低位宽 DSP 打包只有在符号扩展、进位和累加正确时才计入收益。
2. 通用波束阵列：可配置天线并行数、波束并行数、时间复用和权重银行；权重由运行时端口更新，输入/输出持续可观测。
3. 一维 FFT：32/64/128 长度、流水/SSR 并行度、自然/倒序输出、真实位宽与缩放；同时计入重排。
4. 完整二维 FFT：行列转置、bank conflict、乒乓区、补零和两极化调度。比较通用与剪枝/平凡旋转优化版本。
5. Gridding：真实多输入碰撞、连续帧清零/epoch 标签、K=4/9/25，核系数更新与多写端口冲突；不能只综合孤立乘法器。
6. 像素 XX/YY/XY*、积分和输出，包含有效掩码、溢出、稀疏/无效数据处理。

主目标固定现有 `xcku5p-ffvb676-1-i`。KU11P/KU15P 先选工具实际支持的候选封装，统一 -1 等级比较；精确板卡确定后重跑。工具、器件和 IP 许可证需记录实际可用性，不能把许可证失败当算法资源不足。

所有核使用真实握手与外部可变数据，不用全常量输入/权重导致综合优化掉算术。检查未连接/裁剪路径、推导 RAM 类型、DSP 映射、流水延迟和实际 initiation interval。OOC 资源与时序只作为筛选，不作板级结论。

## 阶段 C：架构上限与 routed 验证

对有希望的参数逐步增加并行度，先找资源上限，再对边界附近配置实施布局布线。不得仅依据综合估计 WNS 声称能力上限。

报告 LUT/FF/DSP/RAMB36/URAM、分模块资源、所有时钟、WNS/TNS/WHS/THS、未约束路径、DRC、CDC、路由拥塞和高扇出。完整源/IP/XDC、工具版本、seed/策略、git SHA 与 manifest 哈希均要留存。计算性能必须由“完整时刻/帧实际完成数 ÷ 有效周期”得到，包含转置、清零、窗口边界和输出反压。

算法负载至少包括：无反压、合理反压、持续反压、边界重复切换、配置更新、量化极端值。非停顿数据源通过有限 admission buffer 与丢失记账连接，不能由算法 ready 随意暂停输入。

失败原因按 DSP、LUT、BRAM/URAM 容量、内存端口、路由/时序、输入和输出分别记录；一次失败不能写成“KU5P 不行”。需确定是在当前架构下，还是器件/板卡的硬性约束。

## 阶段 D：真实接收 shell 与缓存

先完成一个 100G 接收接口的可重建 shell：CMAC/FEC/GT、时钟复位、UDP 解析、时间窗口 admission、源/极化映射、乱序对齐、丢失掩码、统计和独立输出。按现有板引脚与原理图核对实际 QSFP 位置，不照搬名称。

至少比较三种架构：

| 架构 | 目标与必须证明的条件 |
|---|---|
| 片内有限窗口 | 测可接受的最坏源偏差，算法与网络共享片内 RAM 后仍有余量 |
| 片内对齐+DDR 扩展 | 测旁路与扩展切换、持续负荷、顺序保证、过期清理和显式超窗丢弃 |
| 全量 DDR 分块重排 | 先测写+读净吞吐与随机访问效率，不满足就降低单片入口或淘汰该架构 |

DDR 先审计当前 MIG/地址与 ECC，再测长突发、实际包尺寸、行列转置混合访问、刷新/ECC/仲裁造成的停顿分布。不能只用全顺序写入峰值作容量证明。

协议故障测试：乱序、丢包、重复、过期、超前、未知源、错频率、截短、错误长度、MAC 错误、epoch/config 切换、窗口环绕、计数器回绕、持续过载、源时钟偏移、复位和输出阻塞。每一种都验证时间不重排错、有效数据不串窗、异常可计数、缓存不无限增长。

第二 QSFP 的 4×25G 或软 100G 只在单口版本通过后评估，须把新增 MAC/PCS/FEC 和重排成本加入完整设计，不能复用“裸算法可放下”的板数。

## 阶段 E：系统与板卡选择

将 routed 的 `Qbf`（complex-MAC/s）、`Qfft(G)`（单极化完整空间变换/s）、`Qgrid`（核点更新/s）与实际网络和输出代入：

- 直接波束：`Bcard ≤ Qbf/(N×P×M×α)`。
- 空间 FFT：`Bcard ≤ Qfft(G)/(P×α)`。
- EPIC gridding：`Bcard ≤ Qgrid/(N×P×K×α)`。
- 所有模式同时受 `Rscience/(N×P×q×α)`、缓存、系数和输出限制；共享资源不能把独立 OOC 峰值直接拼起来。
- 信道粒度：`L=floor(Bcard/(Btotal/C))`，`Kboards=ceil(C/L)`；若 L=0，必须降低单信道宽度或跨板拆分，而不是输出一个虚构板数。

按 KU5P/KU11P/KU15P、带宽、位宽和科学输出生成实际包络与总成本。只在有 full-shell、时序和有界抖动证明后，才提出采购规模。

后续上板与外部发包由具体实验任务执行，保存实际位流身份、有限运行时长、温度/功耗、链路错误和丢失计数。当前项目规划没有启动旧工程中暂停的硬件、驱动或系统实验。

## 推荐工作包及优先级

第一阶段执行 AF-000 的离线设计与验证，已拆分为 P1-01 至 P1-06，详见 [第一阶段任务目标](phase-1-objectives.zh-CN.md)。本文件保留后续完整综合与硬件验证路线。

1. **AF-000（首要）：频率分发与接收缓存**。冻结 RFSoC→交换机→KU5P 的包布局、时间标签和信道映射；计算端口实际占用、pps 与 incast；比较原始电压环形槽、到包即做线性累加、DDR 扩展。建立 256 源的离线故障注入参考，给出最小必要缓存、释放截止和 DDR 读写预算。细则见 [重点方案](corner-turn-and-buffer.zh-CN.md)。
2. **AF-001：科学参考**。确定低/高频子带、三种几何、数值约定和场景，生成独立天空参考；使用 AF-000 的时间/缺失/布局契约。
3. **AF-002：算术筛选**。现有 KU5P 的复 MAC、完整 64² 空间 FFT、碰撞可控的 3×3 gridding，先固定 I/Q8→内部18bit；同参数比较 KU11P/KU15P。不能用裸核吞吐跳过 AF-000。
4. **AF-003：接收与缓存集成**。固定单口 100G，与最有希望的算法组合；核实 DDR 持续读写和完整 shell 的时序，确认实际每片带宽。

本项目当前只交付计划、平均容量与包级预算计算器。AF-000 的 256 源事件仿真、协议 RTL、DDR 测试，以及 AF-001/002/003 的算法 RTL 验收均未执行。
